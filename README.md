# Combat Online Plagiarism with AI

An AI-powered plagiarism detection system built using **Natural Language Processing (NLP)** and a **Support Vector Machine (SVM)** model. This project detects similar or duplicated text content across documents using text preprocessing, TF-IDF vectorization, cosine similarity, and machine learning techniques.

---

## Features

* Detects plagiarized or duplicated text
* Uses **TF-IDF Vectorization** for feature extraction
* Implements **SVM (Support Vector Machine)** model for classification
* Text preprocessing using NLP techniques
* Simple and interactive web interface using Flask
* Model and vectorizer saved using Pickle (`.pkl`)

---

## How It Works

1. User enters or uploads text.
2. Text is cleaned and preprocessed.
3. TF-IDF converts text into numerical vectors.
4. SVM model predicts whether the content is plagiarized.
5. Similarity score is calculated using cosine similarity.
